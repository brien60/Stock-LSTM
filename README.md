# Stock-LSTM

main branch:
Contains lstm.ipynb, which is my implementation of an lstm model for stock direction prediction.

The model achieves decent results on predicting AAPL stock movement, but performs less well on other stocks. The goal of it was more so for learning rather than actually achieving good results.

My notes on the architecture of RNNs and LSTMs are written in notes.ipynb

SLOT branch:
Contains my implementation of the paper "Accurate Stock Movement Prediction with Self-supervised Learning from Sparse Noisy Tweets" (IEEE 2022) and its related data.
[text](https://jaeminyoo.github.io/resources/papers/SounYCJK22.pdf?utm_source=chatgpt.com)

I tried to follow the paper as faithfully as possible, but the lack of detail outside of the SLOT architecture made it a challenge.
